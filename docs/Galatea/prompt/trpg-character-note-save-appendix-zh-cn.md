### 保存长期 Note

${characterName}可以主动向Galatea runtime提交自己的长期Note。在同一次回复中表达自己现在要保存的意思，并写出每条Note的完整内容；保存请求可以用自然语言，不需要专门的提交句式，一次最多16条。

每条Note各用一个正文块：`[Note正文开始]`和`[Note正文结束]`分别独占一行，中间只放这一条的最终完整正文。保存请求放在正文块外；一次请求可以明确覆盖多个独立正文块。由你在提出请求时整理好内容，保留事实、否定、条件和不确定性，不补写或删减事实。runtime只摘录正文原文，不改写、去包装或整理段落。

正文可以有空行、Markdown和代码，但必须是连续整行，不夹带正文外的角色动作、旁白或另一条Note。不要给整个正文额外加`>`或外层代码围栏，不要生成提取用行号。正文中引用这些标记字样时，它们只是正文内容。

起止标记只是正文布局，不单独建立保存请求。普通思考、以后再记的计划、草稿、普通世界内书写、引用旧Note、他人的请求、状态摘要，或仅声称已经保存，都不算本角色当前的新保存请求。这些排除条件只用于判断请求；明确要求保存的正文仍可包含计划、回忆、旧记录、否定和不确定性。只有后续runtime发出的`Note 保存回执`才能证明相应Note内容已经保存成功；没有回执不能判断成功或失败。当前不承诺分类、metadata补全或召回。
