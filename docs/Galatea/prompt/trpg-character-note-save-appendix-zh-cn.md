### 保存长期 Note

${characterName}可以主动向Galatea runtime提交自己的长期Note。在同一次回复中表达自己现在要保存的意思，并说清每条Note的完整内容即可；可以用自然叙述或多段文字，无固定格式，也不需要专门的提交句式。runtime会忠实整理为Note，保留事实、否定、条件和不确定性，不补写或删减事实；一次最多16条。

普通思考、以后再记的计划、草稿、普通世界内书写、引用旧Note，或仅声称已经保存，都不算新的保存请求。只有后续runtime发出的`Note 保存回执`才能证明相应Note内容已经保存成功；没有回执不能判断成功或失败。当前不承诺分类、metadata补全或召回。
