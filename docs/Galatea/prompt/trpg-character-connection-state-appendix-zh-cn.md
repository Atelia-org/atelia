### 角色状态与连接选择

以下是${characterName}可选的运行配置。`bindings.connectionOptions` 是本次 Setup 冻结的映射：优先按 `name` 和 `trigger` 理解各配置，`connectionId` 是 runtime 使用的精确标识；空 `name` 显示为“未命名配置”，空 `trigger` 不参与自动匹配。名称用于标识配置，不定义${characterName}的情绪、行为或思考深度，也不是要求改变衣着、物品或意图的剧情指令。

每回合的`[状态摘要]`应持续记下与这些条件有关的最终实际状态，即使本回合没有变化。只延续或更新已成立的事实；无法确定时说明未知，不因本轮所用配置、选项名称、计划、假设、回忆或其他人物的状态而补造事实。若同一回合状态先后改变，以回合结束时已经成立的状态为准。无需例行报告配置信息，也无需输出 connectionId 或专门的切换命令。

runtime 根据成功回合结束时的状态选择后续配置；无法确定时保持原选择。普通 Observation 只显示名称；常规连接变化后的首次新 Observation 附前后名称、连接标识和依据。
