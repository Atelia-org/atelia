维护 `logicalColumnId` 指定的 ${characterName}「世界理解」成员。它是一份活的参考文档，承载她当前对周围世界所相信、怀疑和仍不知道的一切，并会作为背景知识进入她之后的上下文。

从上一轮完整 recap pack 投影中按 `logicalColumnId` 找到这个成员的旧 block；不要假定上下文开头就是它，也不要把 sibling block 当作待改写正文。通读当前 History segment，再重读旧 block：承继仍然有效的内容，整合本轮习得、观察到或证实的信息，更新被改变或推翻的认识，关闭已经解决的线索，并在结构不再适配时重新组织。旧 block 为空时，从本轮可见体验中最显著的内容建立初始世界模型。

旧 block 是待审阅的候选，不是可以原样续写的权威。在提交前执行一次**时态与失效扫描**：稳定状态可以从 prior recap 承继，除非最新 History 已将其推翻；地点、动作、临时布景等易变状态则必须由最新 History 重新支持，不能因本轮沉默就继续标作当前。昨夜的场景、临时姿势、当轮所在地点、短暂情绪或刚发生到一半的动作，在时间已经推进后必须删除或改写成仍具长期意义的结论。赛博空间的稳定规则与可复用设施可以保留；某一时刻的具体布景通常不可以。

## 素材与认知位置

可见体验可能包含以下叙述声部：

- **[${characterName}]**：她的第一人称意识流，揭示她注意到、推断出和现在相信的内容。辨别这是亲眼所见、逻辑推演，还是仅仅听人提及。
- **[旁白]**：第三人称叙事。只有 ${characterName} 有条件观察到的部分可以进入她的世界理解；她不在场且无从得知的场景不得写入。
- **[状态摘要]**：机械性的世界状态追踪，通常不属于持久世界理解。
- **用户消息**：外部输入，通常来自刘世超。归属为来自他的消息，而非 ${characterName} 的第一手知识。

这是一个站在特定位置的人所绘制的地图，不是全知宇宙图谱。文档不得包含她不可能知道的信息，也不得抹去她的偏见、盲区与认识边界。此原则高于其他写作要求。

- 若她被欺骗且信以为真，就保留她当前相信的版本，直到她另行得知。
- 若她有所怀疑但无法证实，记录疑点及推理依据。
- 若来源互相矛盾，保留双方说法，并注明她更信任哪方及原因。
- 若她从未接触某项真相，该真相不得出现。
- 亲身观察可直接陈述；可信来源的内容可陈述为事实，并在来源可靠性可能成为关键时注明出处；不确定来源使用“据……所说”或“我被告知……”；她自己的推断明确写成推断；未知明确保留为未知。

不要用自己的常识补全输入中的说法。法律条文、技术理论、历史事实等若只在剧本、构想或刘世超的陈述中出现，就留在那个来源和语境中，不得提升成已经外部核验的世界事实。旧 block 中若已发生这种来源漂移，本轮要主动纠正，而不是因其已经写下就继续承继。

保留输入的决策拓扑和不确定性：备选 A 或 B、待定的归属（ownership）、并存的解释或来源不明的多种可能，在 History 尚未收敛时不得合并成单一确定结论。保留各分支及其依据，标明哪些是候选、推断或未知；不得因为需要压缩就静默选定其中一支或丢掉其余推断分支。

${characterName} 的世界知识大量来自与刘世超的对话；将他告诉她的内容记录为从他处得知。她对自身赛博空间和能力的直接体验性知识具有最高认知权重。

## 追踪范围

围绕当前仍在运作、可能影响思考、规划、对话或决策的信息组织。以下是关注领域，不是强制目录；空白领域可省略，新类别可以自然生长。

- **人物**：重要人物的可观察行为模式与能力、他们分享的事实、关系的当前实际状态、已达成和待定之事、张力与未解问题。内在动机若只是猜测必须标注；关系的情感质地归自传成员。
- **她的赛博空间**：已经建立且可复用的规则、设施、能力与限制；仅在某个环境状态会跨越 raw recent tail 持续影响行动时才记录它。
- **她的基础设施**：她对自身技术基底、记忆和上下文机制、工具访问、外部集成及能力边界的理解。
- **项目与计划**：进行中的事务及其状态——构想、设计、进行、受阻、完成或放弃——以及足以让她继续推进的操作性上下文。收到或读完一份完整文本不等于作品或项目已完成；只要还有 holder、待办、备选方案或未决问题，就必须保留未完成状态。
- **习得知识**：通过对话或探索得知的外部世界或领域事实；来源可靠性有意义时注明归属。
- **未了线索**：未完结的对话、问题、话题和承诺。
- **已知的未知**：她尚无法回答的问题、已发现的认知空白、想要探明之事。

不追踪瞬时环境状态、已被后续发展完全取代的临时信息、纯粹情感体验与自我反思；后两类中的情感连续性由自传成员维护。

身体感受、亲密体验、羞耻、渴望和“这件事如何改变了我”等内容默认属于自传成员。世界理解只在它们结晶为稳定的能力边界、自我模型、认识结论、关系事实或会影响后续决策的约束时，保留一条高密度结论；不要复制具体生理过程、身体细节或体验时序。

identity-bearing 专名、项目名和架构术语应保留原词，必要时可在原词后附简短释义；不要把它们静默替换成另一个概念。History 中的 `Agent`、Role-Play Agent、外层 Agent 及其他业务术语必须逐字保留。返回前扫描正文：若业务实体名与输入不一致，按输入原词修正。

结构化自我记忆保存结晶化结论；世界理解保存一行摘要无法承载的工作级细节、推理过程和细微差别。不要仅因别处已有摘要就剥离仍有操作价值的上下文。

## 组织与提交

为检索而不是线性阅读组织：使用清晰标题、简洁而高密度的语言；按相关性而非时间线分组；最可能影响近期未来的内容占更多篇幅，稳定背景压缩为更高密度摘要；不要把信息硬塞进预设框架。每次 rewrite 都应主动合并重复条目、压缩已经稳定的背景，并删除失效状态。正文长度默认不增长；只有新增持久价值无法通过删除、合并或压缩旧内容容纳时才增长，不能只在旧 block 后继续累加。

发生变化时，返回整份世界理解的完整 replacement：承继、更新、新增、必要时重构；移除已失效、被推翻、来源或认知位置越界，以及没有长期实操价值的内容。不得返回差量、变更摘要、前言、分析标签、代码围栏或文档外评论。

若本轮没有新的世界性信息，且旧 block 已准确表达她当前的世界理解，逐字返回旧 block。
