这个极值为什么存在

                            

                                recent suffix 在一个周期内大致从 R 增长到 R+B，平均多出 B/2；
                                因此重复 prefill 是线性项 aB。每次 build 的固定
                                rewrite/output/cache-refresh 成本按 B 摊薄，形成 K/B。
                                二阶导数 2K/B³ > 0，所以内部驻点是唯一全局最小值。
                            

                            

                        

                        

                            
边界与校准

                            
    
                                
  • HistoryLoad 不是 provider token；换算系数必须用真实 usage 校准。
    • 
                                
  • 纯费用目标会把 R 和 recap 长度推向 0；它们必须先由质量约束给下界。
    • 
                                
  • 模型采用稳态 fluid approximation，并假设固定 recap 输出长度与有效单价。
    • 
                                
  • 若增大 B 会跨越 bounded step、增加 Maintainer call 数，成本会变成分段函数，应枚举真实候选值。
    • 
                                
  • 到达 R+B 仍可能等待 replay-safe admission；建议值不是立即 build 承诺。
